Architecture summary

A modular system that can scale from MVP to tracking and CV.

Necessary APIs

The product can be implemented with a staged integration strategy.

Sportmonks Football APIPlayer, team, league and statistics baseline for the MVP.
Video storageS3-compatible storage for uploads, clips, thumbnails and permissioned access.
Tracking dataSkillCorner or similar provider when the club reaches the tracking stage.
Search layerPostgreSQL plus pgvector for filterable search and internal reference matching.

Security model

A club system needs clear access rules and traceability.

Roles

Scout, analyst, sporting director, admin and read-only stakeholder.

RLS

Row-level security keeps club data partitioned and protected.

Audit

Every shortlist, annotation and export is logged with provenance.

Privacy

Video rights and player data usage stay explicit and contract-aware.

Build phases

The roadmap is intentionally staged so the platform remains usable before the CV stack matures.

Phase 1

Data ingestion, normalization, club DNA, fit-matching and explainable shortlists.

Phase 2

Tracking integration, video analysis, off-ball metrics and stronger under-the-radar detection.

Phase 3

Monitoring during the season, automated re-ranking and richer model-assisted workflows.
